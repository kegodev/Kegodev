# Profile artwork

Local SVG graphics for the main profile README. The visual system uses charcoal, warm cream and burnt orange, with large type and simple layouts.

- `hero-premium.svg` — profile introduction and typographic mark.
- `project-ecosystem.svg` — overview of four areas of work.
- `fuel-for-the-work.svg` — closing illustration.

Keep this directory alongside the root `README.md` when uploading to GitHub. The graphics use standard SVG elements without scripts, external fonts or remote images. Essential profile and project information also appears as readable text in the main README.
